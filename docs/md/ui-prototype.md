# 目标与范围
- 目标：为采集、工作流、预览与模板、发布、历史记录、系统设置提供统一工作台体验
- 首页仅展示统计类信息卡片：概览、任务时间轴、任务日志
- 其他功能在对应栏目页面内展示

# 信息架构
- 概览（首页）
- 采集源
- 工作流
- 预览与模板
- 发布中心
- 历史记录
- 系统设置

# 页面设计摘要
## 概览
- KPI 统计卡片（采集、入选、发布、异常）
- 任务时间轴（采集 → 清洗 → 渲染）
- 任务日志（最近异常与成功事件）

## 采集源
- 采集源卡片列表（状态、规则摘要）
- 规则配置区（筛选条件、频率、优先级）
- 试跑结果预览

## 工作流
- 流程节点视图（采集、打分、生成、发布）
- 关键配置（排序权重、入选数量）
- 模板绑定与输出设定

## 预览与模板
- 模板画廊（缩略图、标签）
- 预览对比（左右双列）
- 导出与复制

## 发布中心
- 平台卡片（微信、知乎等）
- 发布队列（状态、耗时、错误）
- 失败重试入口

## 历史记录
- 记录表格（时间、类型、来源、结果）
- 详情抽屉入口（日志、参数、产出）

## 系统设置
- 环境配置（API Key、AppID/Secret）
- 数据存储开关与连接状态
- 通知渠道配置

# 视觉与布局
- 左侧导航 + 顶部状态条 + 右侧内容区
- 深色背景与纸感卡片风格保持不变
- 重点信息采用 KPI 卡与时间轴组件

# 代码落地结构
- docs/prototype.html（概览首页）
- docs/sources.html（采集源）
- docs/workflows.html（工作流）
- docs/templates.html（预览与模板）
- docs/publish.html（发布中心）
- docs/history.html（历史记录）
- docs/settings.html（系统设置）
